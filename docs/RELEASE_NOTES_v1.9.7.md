# Fairumanējā v1.9.7（测试版）

> **Pre-release / 测试版**：本版本以测试版名义发布。

---

## 本次更新内容（v1.9.7）

### 濒危多语言切换（新增）

- 设置 → 实验性功能 → 濒危多语言切换，新增 5 种语言：满语、锡伯语、夏威夷语、毛利语、切罗基语。
- 点选一种语言后，点“确认”才切换，点“取消”不切换。
- 满语、锡伯语使用真正的满文蒙古文 Unicode 书写（U+1800–U+18AA），不是拉丁化转写；例如 baturu = ᠪᠠᡨᡠᡵᡠ、manju gisun = ᠮᠠᠨᠵᡠ ᡤᡳᠰᡠᠨ、bithe = ᠪᡳᡨᡥᡝ。
- 应用内捆绑 Noto Sans Mongolian 字体（SIL OFL 1.1），手机系统没有满文字体也能正常显示；许可证全文随包提供，关于页开源组件表新增第 7 项。
- 夏威夷语：拉丁字母 + kahakō、ʻokina；毛利语：拉丁字母 + 长音符；切罗基语：切罗基音节文字。
- 如实说明：Android 没有原生竖排蒙古文布局，满文、锡伯文目前是横排显示，字形旋转 90 度、从下往上读，可以阅读，但不是传统竖排；部分生僻词拼写仍在核对，欢迎母语者复核。

## 上个版本更新内容（v1.9.6）

### 实验性功能（新增）

- 设置新增“实验性功能”入口；点进之前每次先弹警告框，详细说明可能造成的后果，确认才进入，取消留在设置页。
- **UI 引擎**：切换整个 App 的界面风格——Material Design 3（默认）、M3 Expressive（更圆润、更鲜明的造型）、Miuix（小米 MIUI 风格）；切换到别的引擎前先弹确认框，确认才切换；三个引擎的颜色都跟随应用配色与动态颜色。
- **液态玻璃**：用 QWEA0 的 Liquid-Glass-Android（真 SDF 折射）把 UI 面板变成半透明；点行选模式（半透明 / 透明模糊 / 全透明，半透明为默认），点开关开启，开启前先弹确认提示，确认才开，取消不开；玻璃 tint 跟随当前应用主题色变化。
- **应用配色**：由 25 色扩展到 52 色，选好点确认才应用。
- **字体颜色**（外观页新增）：52 种颜色，分浅颜色 / 深颜色 / 基础颜色，默认黑色，选好点确认才应用，取消不切换；作用于文件列表名称、标题、设置文字等主要文字。
