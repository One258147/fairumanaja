# Fairumanējā v1.9.7.8 更新内容

## 设置页改版（样式和布局，功能不动）

- 设置页分成两组：语言与外观（多语言设置、外观）、应用（开屏动画、关于、实验性功能）。
- 每组上面加分组小标签（颜色跟应用配色走），每组一个白色大圆角卡片。
- 行首图标放进浅色圆圈里（圆圈色跟应用配色走）；导航行右边仍是箭头，开屏动画行右边仍是开关。
- 卡片内行与行之间加细分隔线。
- 5 行一个不少、顺序不变，每行的标题、副标题、当前值、点开的页面、开屏动画开关行为都不变；新增的两个分组名补了 23 种语言的翻译（拿不准的已标 UNCERTAIN，需母语者复核）。

## 搜索卡顿修复

- 修复搜索卡顿：之前每次敲一个字母，搜索框都在主线程上同步递归扫描整棵目录树（`/storage/emulated/0` 又大又深），每敲一下界面就冻住一阵；主线程一卡，输入法连接跟着丢，查询被清空、列表跳回完整目录、文件夹大小缓存也被清掉、副标题跟着闪。现在敲键只改查询（立即返回、不扫盘），250ms 防抖后在后台线程扫描，算完且查询没变才上屏；旧查询的线程算完直接丢弃，不会覆盖新结果；搜索时不再清空文件夹大小缓存，已算好的大小留着，副标题不闪。
- 搜索仍是递归全盘搜索（上限 500 条），SAF / Shizuku 模式只是在内存里过滤已有条目，不扫盘，走原来同步路，不受影响。
- 长名在搜索结果里仍最多五行完整显示，不截断、无省略号。
