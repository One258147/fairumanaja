# Fairumanējā v1.9.8 更新内容

## 新增

- 设置页新增“一键恢复默认设置”按钮：位于“应用”分组卡片下方，长椭圆形主色按钮。点击后弹出确认框，确认后将语言、主题模式、动态颜色、应用配色、字体颜色、UI 引擎、开屏动画、排序、双窗格、显示隐藏文件恢复为默认设置，书签、置顶文件夹、自定义储存和回收站不受影响。
- 多语言设置新增“跟随系统”选项，位于语言列表最上方，默认选中；全新安装时默认跟随系统语言。
- 新增 25 种语言，语言总数达到 43 种：意大利语、瑞典语、挪威语、波兰语、荷兰语、丹麦语、希腊语、埃及语（埃及阿拉伯语）、匈牙利语、拉丁语、梵语、土耳其语、印地语、菲律宾语、马来西亚语、印度尼西亚语、波斯语、亚美尼亚语、粤语、美式英语、文言文、彝语、哈萨克语（中国哈萨克语，阿拉伯字母）、西里尔哈萨克语、苗语。语言页按语言英文名 A–Z 排序。
- 文言文使用简体字。

## 新增（收尾补充）

- 排序新增“按类型”与“逆向排序”：排序框现有 5 个圆圈单选——按名称、按日期、按大小、按类型、逆向排序；行间距收紧。选“逆向排序”把当前排序方式的结果倒过来，文件夹仍在前、文件在后，各自内部倒序。
- 排序框新增独立复选框“仅用于文件夹”，位于两列布局第一行左面。勾上后，任意排序方式都只对文件夹生效，文件不参与排序、保持目录原顺序排在文件夹后面；不勾恢复正常（文件夹和文件都排序）。复选框状态独立保存，切换排序方式或逆向排序都不会清掉它，点确认才保存。
- 应用配色重置为 52 个常用颜色（去掉白色与黑色，补了薄荷色与珊瑚色），分组改为基础颜色 / 变体颜色 / 浅颜色 / 深颜色。变体颜色是基础颜色的衍生色，包括黄绿色、薄荷色、珊瑚色、天蓝色、薰衣草紫、桃粉色、玫瑰红、青柠色等。选变体色后全应用配色跟着变。
- “一键恢复默认设置”同时重置新增的逆向排序与“仅用于文件夹”。

## 新增（图像查看器）

- 内置图像查看器：点击任意格式的图片（jpg、jpeg、png、gif、webp、bmp、heic、heif）进入单独的图片页，顶栏显示文件名与“日期 宽×高”，右上角从左到右是背景切换、属性、排序三个按钮。
- 背景切换：黑、白、灰三档圆圈单选，默认黑色，点确认才切换，只有图片区域跟背景色走，顶栏、底栏保持应用配色。
- 排序：横向翻页、纵向排序两档圆圈单选，默认横向，点确认才切换；纵向模式下全部图片上下一列滚动，当前序号取最上面可见的那张。
- 左下角方框：点一下进入选择模式，当前图片打勾，方框变主色底白对勾，旁边显示已选数量；选择模式下点图片本身也能切换该图选中，选到 0 张自动回到正常模式。带选择退出查看器后，主列表进入选择模式，只勾上当前文件夹里的那几张。
- 底栏中间显示“当前序号/总数”，总数是手机里全部图片的数量；右下角是删除、分享、其他打开方式。删除走与主列表一致的回收站确认流程。
- 排序对话框改成两列（3 行 × 2 列）：第一行左面是“仅用于文件夹”方框、右面是按名称；第二行按日期、按大小；第三行按类型、逆向排序。5 个圆圈仍互斥单选，方框仍独立，确认才保存。
- 修复：MediaStore 没填宽高的图片，副标题和属性里曾显示“未知”，现在改从文件头现读尺寸补上。
- 新增 8 条词条（背景切换、黑色、白色、灰色、横向翻页、纵向排序、尺寸、格式），已翻进全部 48 种语言；基线 295 → 303 条，英文 303 条缺 0，其他语言各缺 7 条（6 篇长文 + 变体颜色组标题回落中文）。

## 新增（视频播放器）

- 内置视频播放器：点击视频文件（mp4、mkv、avi、mov、webm、flv、wmv、3gp、m4v、ts、m2ts、mpg、mpeg）进入单独的播放页，打开自动播放；播不了的格式弹提示，不崩溃。
- 顶栏显示文件名与“日期 时长”，底栏有播放/暂停按钮、进度条（当前时间/总时长）、调速按钮；单击视频区域切换控制栏显隐。
- 双击视频区域暂停，再双击继续播。
- 调速：0.5x、0.75x、1x、1.25x、1.5x、2x 六档圆圈单选，默认 1x，点确认才生效；底栏右下角显示当前倍速。（后续底栏重做：调速移到三个点菜单里，底栏不再显示倍速，见下。）
- 播放引擎 ExoPlayer 1.4.1；返回退出播放页后停止播放，不再有声音。
- 新增 4 条词条（调速、无法播放该视频、播放、暂停），已翻进全部 48 种语言；基线 303 → 307 条，英文 307 条缺 0，其他语言各缺 7 条（6 篇长文 + 变体颜色组标题回落中文）。

## 新增（视频播放器右上角按钮）

- 播放页右上角新增三个按钮，左到右：分享、属性、三个点。
- 分享：弹出系统分享框（蓝牙、邮件等），分享当前视频；分享失败弹提示，不崩溃。
- 属性：弹出属性对话框，显示名称、路径、大小、修改日期、时长、分辨率、格式。
- 点三个点弹出菜单，三行开关（拨一下立即生效并保存）：强制铺满全屏（开 = 视频铺满整个区域忽略比例，关 = 按比例适配）、循环播放（开 = 播完重播，关 = 播完停住）、横屏模式（开 = 播放页锁定横屏，关 = 跟随系统）。
- 新增词条已翻进全部 48 种语言；基线 307 → 311 条，英文 311 条缺 0，其他语言各缺 7 条（6 篇长文 + 变体颜色组标题回落中文）。

## 改动（视频播放器底栏重做）

- 底栏改成两行：第一行是进度条（左当前时间、中间圆点滑块、右总时长）；第二行是控制行：快退10秒、播放/暂停（居中、比别的图标大）、快进10秒。
- 调速从底栏移到三个点菜单里：菜单新增第四行“调速”，点后弹出原来的六档调速对话框（0.5x–2x，点确认才生效）；底栏不再显示倍速。
- 循环和全屏不进底栏，只在三个点菜单里。

## 新增（视频播放器上一个/下一个）

- 底栏控制行改成五个按钮，左到右：上一个、快退10秒、播放/暂停（居中、比别的图标大）、快进10秒、下一个。
- 上一个/下一个切换同一文件夹里的视频（只算视频文件，按主列表当前排序排）；播完停在当前视频不跳；到第一个视频时上一个置灰点不了，到最后一个视频时下一个置灰点不了。SAF 进来的视频传 URI 列表同样可切；Root 进来的视频拿不到列表时两个按钮置灰。
- 本次改动没新增词条（两个按钮只用图标）。

## 说明

- 埃及语按现代埃及阿拉伯语翻译；字母排序按语言英文名 A–Z。
- 部分小语种、濒危语言及文言文的译文为尽力翻译，个别词句尚需母语者复核，应用内已作标注。
- 按日期、按大小正序时，文件夹与文件不再混排：文件夹在前、文件在后，各自组内按日期/大小排。

## 新增（更多方式九宫格：顶置改名、播放视频、查看图片、浏览压缩包、编辑文本）

- 九宫格第三个“Pin folder”改名“顶置”（英文 Pin to top），行为不变：只对文件夹有效，点一下置顶/取消置顶。
- 九宫格末尾加四个按钮（9 个变 13 个）：播放视频（只对视频有效）、查看图片（只对图片有效）、浏览压缩包（只对 zip 有效）、编辑文本（只对文本文件有效，其余置灰）。
- 播放视频、查看图片点后进已有的内置视频播放器/图像查看器（普通文件传路径，SAF 传 URI，根目录暂存副本 + 真实路径，三路与主列表点开一致）。
- 编辑文本点后进已有的文本编辑器，能查看、能改、能保存（普通文件传路径，SAF 传 URI，根目录暂存 + 退出时写回真实路径）。
- 文本判定复用 FileUtils.isText，补了 cfg、conf、toml、sql、env、text、srt、vtt、bat、ps1、rb、go、rs、php、lua、dart。
- 新增词条：play_video、view_image、browse_archive（48 种语言全翻）；edit_text 本来就已存在于 48 种语言里，直接复用，不重复建。词条基线 311 → 314 条（英文 314 缺 0，其他语言各 307 缺原来那 7 条）。

## 新增（浏览压缩包：不解压预览）

- 九宫格“浏览压缩包”进新页面（ArchiveBrowserActivity）：不解压，用 ZipFile / ZipInputStream 读目录，列出条目名和未压缩大小；以 / 结尾的是子文件夹，点进去列该前缀下的内容，返回键回上一级，到根再退出；标题是压缩包文件名。zip 里没有显式目录条目时，子文件夹从文件路径里合成出来。
- 点包里的文件条目时只有两个功能：查看属性、分享；文本项再多一个编辑文本；其他功能一律没有（不解压单个文件、不删除、不复制、不改名）。目录条目不能分享。
- 属性显示名称、大小、修改时间、压缩后大小（有就显示）。
- 分享把那一项解到 cacheDir 临时文件再走现有分享流程；临时文件名只取条目名的最后一段，防止路径穿越。
- 包里的文本项点编辑文本：解到临时文件用文本编辑器打开，改完保存后重写整个包、替换该条目再写回（普通文件替换原文件，SAF 用输出流重写，根目录先写回暂存副本再走 Shizuku cp 写回真实路径；新包建好之前原文件一个字节都不动，写回失败弹提示、不丢原包）。
- 损坏/打不开的压缩包 toast 提示后退出，不崩溃。
- 本段没加新词条（属性/分享/编辑文本/压缩后大小都复用已有词条）。

## 新增（媒体页：抽屉图像、视频入口）

- 抽屉工具区新增图像、视频两个入口（带图标），顺序是回收站、文本编辑器、图像、视频、设置；点图像默认图片分类，点视频默认视频分类，两个入口共用一个新页面（MediaActivity）。
- 新页面列出手机里所有的图片和视频（MediaStore，图片查 Images、视频查 Video，与图像查看器同一套查询）；顶部三个分类标签并排居中文字（样式参考已安装应用页：选中项下面一条应用配色下划线）：图片（不含 gif）、视频、动图（gif）。
- 内容默认按日期倒序、一个日期一组（组头：今天、昨天、YYYY-MM-DD）；每行是圆角缩略图（ContentResolver.loadThumbnail，失败显示类型图标）+ 文件名 + “大小 • 时间”（时间格式照主列表）。点图片进内置图像查看器，点视频进内置视频播放器（都传 content URI；播放器拿不到同文件夹列表，上下切换置灰）。
- 顶栏：返回、标题（按入口显示图像或视频）、右上角三个点菜单；没有搜索功能。
- 三个点菜单里有排序、全选。排序跟主界面一样（5 个圆圈单选：按名称/按日期/按大小/按类型/逆向排序，点确认才生效），没有“仅用于文件夹”方框；默认按日期倒序、按日期分组，切到按名称/按大小/按类型时平铺不分组（只要排序方式是按日期就分组，逆向只决定组内和组间顺序）。
- 全选选中当前分类下的全部。长按某项进选择模式（顶栏 ×、已选择 N 项 / 总大小、分享图标、删除图标、三个点；三个点菜单里只有全选）：分享走系统分享（ACTION_SEND_MULTIPLE，直接用 MediaStore 的 content URI）；删除走主列表一致的回收站确认流程（标题删除 + 是否移入回收站 + 大小 + “移动到回收站”复选框默认勾选），有真实路径的走 TrashHelper.moveToTrash（同时尽力删 MediaStore 行，免得列表留 stale 行），没有路径的直接删 MediaStore 行，删完刷新列表；点 × 或返回键退出选择模式。
- 新增词条：media_images、media_videos、media_gifs、media_today、media_yesterday（48 种语言全翻）；排序/全选/删除确认等复用已有词条。词条基线 314 → 319 条（英文 319 缺 0，其他语言各 312 缺原来那 7 条）。
