# Fairumanējā v1.9.7.4 更新内容

## 本次更新（v1.9.7.4）

- 修复：多语言翻译补全。除 6 篇长文（软件介绍、用户协议、隐私权政策、免责声明、许可证、开源组件说明，仍只留中英）外，全部 23 种语言的词条已补齐：中文基准 305 条，英语 305 条，其他语言各 299 条。之前在其他语言下回落中文的界面（外观、液态玻璃、警告框、快捷方式、加密、回收站等）现已翻译。
- 修复：外观页提示精简。主题模式那行提示整行去掉；动态颜色提示只留“开启后，应用颜色跟随系统壁纸颜色变化”；应用配色提示只留“选择应用的主题颜色，界面主色随之变化”；开屏动画提示只留“开启后，每次从桌面启动应用时都会先播放开屏动画”；所有提示小字末尾句号去掉。
- 新增：M3 Expressive 真正重做。现在用更鲜艳饱和的配色、更大圆角、更大更粗的字型，一眼就能和 Material Design 3 区分开。
- 新增：主题设置页按参考重组。外观页改为“主题设置”页：主题风格（Google Material 3 / Miuix 单选）、使用 M3 Expressive 外观开关、启用模糊开关（即液态玻璃）、主题模式、调色板样式（52 色应用配色）、动态颜色、字体颜色、多彩对话框开关。UI 引擎已从实验性功能页移出，由主题设置页接管；原有设置直接映射，不会重置。
