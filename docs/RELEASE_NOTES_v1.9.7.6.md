# Fairumanējā v1.9.7.6 更新内容

## 外观页恢复原来四行布局

- 外观页恢复成一个卡片、四行、图标在左的样子：主题模式、动态颜色、应用配色、字体颜色。
- 主题模式：标题 + 当前值，点后弹菜单（跟随系统/浅色/深色，默认跟随系统），选好点确认才切换；不要提示行。
- 动态颜色：开关 + 确认框，提示只留短版“开启后，应用颜色跟随系统壁纸颜色变化”。
- 应用配色：行标题和选择器标题都叫“应用配色”；52 色选择器按基础颜色、浅颜色、深颜色三组列出（52 个颜色一个不少），选好点确认才改；动态颜色开着时置灰点不了。
- 字体颜色：行标题、52 色分组选择器、确认才切换的流程不变。
- 外观页不再有主题风格单选卡片和 M3 Expressive 开关；M3 Expressive 引擎本身保留，切换只走实验性功能页的 UI 引擎行。
- 删掉不再用的 7 条词条（主题设置、主题风格等）。
