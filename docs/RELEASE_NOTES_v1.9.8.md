# Fairumanējā v1.9.8

## 软件介绍

Fairumanējā 是一款开源的双窗格文件管理器，采用 Material Design 3 界面，目标是成为 MT管理器的开源替代品之一，也是少数支持中国少数民族语言的软件之一（藏语、维吾尔语、壮语、传统蒙古文、西里尔蒙古文等）。

支持 43 种语言，实验性功能里另有 5 种濒危语言（满语、锡伯语、夏威夷语、毛利语、切罗基语）。功能包括：双窗格浏览、复制 / 剪切 / 粘贴、回收站、文本编辑器、压缩包不解压预览、内置图片查看器 / 视频播放器 / 音乐播放器、媒体页、Shizuku root 访问、SAF 存储访问、自定义本地储存。

## 更新内容（合并 v1.9.7.3 – v1.9.8，自上次已发布的 v1.9.7.2 起）

### 新增

- 内置图像查看器：点任意格式的图片（jpg、jpeg、png、gif、webp、bmp、heic、heif）进单独的图片页；右上角背景切换（黑 / 白 / 灰，默认黑，确认才切）、属性、排序（横向翻页 / 纵向排序，默认横向，确认才切）；左下角方框进选择模式，退出后主列表进入选择模式；底部中间显示当前序号 / 手机全部图片总数；右下角删除、分享、其他打开方式。
- 内置视频播放器：点视频进单独的播放页，自动播放；双击暂停 / 恢复；底栏两行：进度条 + 上一个、快退 10 秒、播放 / 暂停、快进 10 秒、下一个（同一文件夹里的视频，到头 / 到尾对应按钮置灰）；右上角分享、属性、三个点菜单（强制铺满全屏、循环播放、横屏模式三个开关，调速 0.5x–2x 六档）。
- 内置音乐播放器：点任意音频进新页面立即自动播放；更多方式里新增播放音乐，对视频用播放音乐只放视频里的声音；底栏同样是上一个、快退 10 秒、播放 / 暂停、快进 10 秒、下一个，支持循环与调速。
- 媒体页“图像与视频”：抽屉工具区一个入口，列出手机里全部图片、视频、音频、动图（图片 / 视频 / 音频 / 动图四个分类，音频排在视频后面）；默认按日期倒序、一个日期一组；长按进选择模式；右上角菜单有排序、全选，没有搜索。
- 更多方式九宫格：第三个“Pin folder”改名“顶置”；末尾新增播放视频、查看图片、浏览压缩包、编辑文本（共 13 个）。
- 浏览压缩包：不解压预览压缩包内容，包里的文件只支持查看属性、分享，文本文件还能编辑文本（保存写回压缩包）。
- 路径跳转：点主界面顶部路径弹出“跳转”对话框，输入路径点确定自动跳过去（没有粘贴按钮）；路径不存在弹提示，不跳转、不崩溃。
- 创建 HTML：主界面右上角菜单新增“创建HTML”，输入任意名字点确定，在当前路径创建一个 .html 文件；点 .html 文件自动进文本编辑器查看、编辑代码，建完也自动打开编辑器。
- 新增 25 种语言，语言总数 43 种：意大利语、瑞典语、挪威语、波兰语、荷兰语、丹麦语、希腊语、埃及语（埃及阿拉伯语）、匈牙利语、拉丁语、梵语、土耳其语、印地语、菲律宾语、马来西亚语、印度尼西亚语、波斯语、亚美尼亚语、粤语、美式英语、文言文、彝语、哈萨克语（中国哈萨克语，阿拉伯字母）、西里尔哈萨克语、苗语；语言页按英文名 A–Z 排序；多语言设置新增“跟随系统”选项，全新安装默认选中。
- 设置页新增“一键恢复默认设置”按钮（长椭圆形，实验性功能下方），点后弹确认框，确认才重置语言、主题、动态颜色、配色、字体颜色、UI 引擎、开屏动画、排序、双窗格、显示隐藏文件；书签、置顶、自定义储存、回收站不动。
- 排序新增按类型、逆向排序（共 5 个圆圈单选），新增独立复选框“仅用于文件夹”（勾上后任意排序方式都只排文件夹）；排序框改成两列布局，方框在第一行左面。
- 应用配色重置为 52 个常用颜色（去掉白色与黑色），分组为基础颜色 / 变体颜色 / 浅颜色 / 深颜色，变体颜色是基础颜色的衍生色（黄绿色、薄荷色、珊瑚色等）。

### 改进

- 列表行收紧为 MT 管理器密度：一屏约 12–13 行。
- 设置页重排：语言与外观、应用两个分组，图标圆圈样式。
- 搜索卡顿修复：输入 250 毫秒防抖，后台线程搜索，不再每敲一个字就全盘扫描。
- 外观页恢复成原来的 4 行（主题模式 / 动态颜色 / 应用配色 / 字体颜色）；液态玻璃、多彩对话框删除；UI 引擎保留在实验性功能页。
- 提示文字精简：主题模式提示删掉，动态颜色、应用配色、开屏动画提示改短，所有提示去掉结尾句号。
- 媒体页右上角菜单位置修复（原来弹在左下角盖住列表，现在贴在按钮下面）；抽屉里图像、视频合并成一个“图像与视频”入口。

### 修复

- 夏威夷语、毛利语、切罗基语剩余词条补齐。
- 图像查看器里 MediaStore 没填宽高的图片曾显示“未知”，现在从文件头现读尺寸补上。
- 按日期、按大小正序时，文件夹与文件不再混排：文件夹在前、文件在后，各自组内排序。

## 说明

- 埃及语按现代埃及阿拉伯语翻译；哈萨克语按中国哈萨克语（阿拉伯字母）翻译；文言文用简体字。
- 部分小语种、濒危语言及文言文的译文为尽力翻译，个别词句尚需母语者复核，应用内已作标注。
- 媒体页里点视频进播放器时，上一个 / 下一个按钮置灰（没传播放列表）、标题显示的是数字不是文件名，这个问题还在等定修不修；图像查看器里删图后 MediaStore 会留一行旧记录，下次再进会显示 Something went wrong（不崩溃），修不修也在等定。
