# Fairumanējā v1.9.7.5 更新内容

## 恢复实验性功能页 UI 引擎

- 实验性功能页加回“UI引擎”一行：点行弹出菜单（Material Design 3 / M3 Expressive / Miuix），选别的先弹确认框，确认才切换。
- 跟外观页的“主题风格”单选卡片是同一个开关（同一份偏好），两边同步。

## 删除多彩对话框

- 外观页去掉“多彩对话框”一行；对话框一律用主题色。

## 彻底去掉液态玻璃

- 外观页去掉“启用模糊”一行；实验性功能页去掉液态玻璃模式选择行和开启确认框。
- 全 App 不再有玻璃半透明/模糊效果；HAZE 依赖已从编包中去掉。
- 实验性功能警告框去掉液态玻璃那一条；关于页开源组件表去掉 HAZE 一项并重排。

## 名字改回“外观”

- 设置页入口和页面标题都改回“外观”（主题风格、M3 Expressive、主题模式、调色板样式、动态颜色、字体颜色都在，内容和排版不动）。

## 调色板样式选择器分组

- 外观页“调色板样式”的 52 色选择器按基础颜色、浅颜色、深颜色三组列出（52 个颜色一个不少）；选好点确认才改、取消不改；动态颜色开着时置灰点不了。
- 三组标题目前只有中文和英文，其他语言暂时回落中文。
