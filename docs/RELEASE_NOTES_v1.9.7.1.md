# Fairumanējā v1.9.7.1（测试版）

1.9.7 的过渡小更新。

## 本次更新内容（v1.9.7.1）

- 界面框架从 View 全面换成 Jetpack Compose。
- 真 Miuix：改用 compose-miuix-ui/miuix 库；UI 引擎切换后，所有界面都跟着换，不只是设置页和主界面。
- 液态玻璃改用 HAZE 库；三种模式：半透明（半透明 + 实时毛玻璃模糊）、全透明模糊（面板全透明、背景真实模糊）、全透明（面板全透明、无模糊）。
- 实验性功能警告框：满语、锡伯语的标题和正文翻成真满文、锡伯文，不再回落中文；删掉最后一句“确认后才会进入实验性功能页，取消则不进入。”（所有语言都删）。
- 实验性功能页：去掉第一句提示和 5 种语言的文字，新增小提示“目前仅支持5种语言，后续可能会添加”；5 种语言本身保留。
- 主题模式重做：点后弹出菜单（跟随系统 / 浅色 / 深色），默认跟随系统，选后点确认才切换。
- 字体颜色管全 App 所有文字，不管哪个 UI 引擎。
- 开屏动画：图标和名字都改成 1.5 秒快速旋转 360 度；名字从屏幕底部弹至图标下面，图标和名字之间留空隙。
- 修复：双窗格副标题大小显示、搜索里删文件后不刷新、冷启动语言、抽屉顶部文字重叠、液态玻璃开启时抽屉卡片显示问题。
